# CivicSense Mini

A small single-page civic issue tracker. No install, no server. Open `index.html` in a browser.

## Features
- Report civic issues (garbage, pothole, water leakage, streetlight, parking, noise)
- Upvote, change status (Open, In progress, Resolved), delete
- Search, filter by category and status, sort by newest or most upvoted
- Live stats (total, open, resolved)
- Civic tip of the day and a personal pledge checklist
- Dark mode, JSON export
- Data saved in the browser (localStorage)

## Tech
HTML, CSS, vanilla JavaScript.

## Limits (why there is a Pro version)
Data lives only in one browser: no login, no shared database, no map, no photos, no admin role.
